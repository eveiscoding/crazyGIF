# 前端页面与状态清单

更新：2026-11-05。单页编辑器，无路由库，无后端页面。仅显示功能名称、操作说明和状态反馈。

| 区域         | 内容与交互                                                            | 关键状态                               |
| ------------ | --------------------------------------------------------------------- | -------------------------------------- |
| 顶栏         | 应用名称、本地处理提示、功能帮助                                      | 帮助打开/关闭                          |
| 画布         | 场景实时预览、播放暂停、点击图层选择、拖动构图                        | 播放、暂停、素材抠图查看               |
| 抠图辅助控件 | 透明/黑色/白色背景、画笔大小、虚线范围                                | 背景切换、画笔 4–100px                 |
| 画布图层     | 缩略图选择、复制、置顶、移除                                          | 选中图层、0–12 个图层                  |
| 选素材       | 多选/追加上传、素材列表、添加到画布、删除素材、AI、手动抠图、撤销重做 | 0–6 个素材、导入/AI 处理中、失败或取消 |
| 动画         | 四种动画模板、速度、强度、文字动效、循环时长                          | 模板选中；文字静止/弹跳/摇摆/缩放      |
| 构图与文字   | 选中图层大小/角度/位移、导出背景、文案/字号/颜色                      | 无选中时构图禁用，文字仍可使用         |
| 导出操作栏   | GIF、PNG、编码进度与取消                                              | 空闲、编码、取消、失败                 |
| 状态通知     | 读取、AI、错误和取消反馈                                              | 空闲时无默认文案，aria-live 提示       |
| 导出结果     | 预览、类型/大小、下载、分享、关闭                                     | 生成后滚动至结果，可长按保存           |
| 帮助         | 多素材/图层语义、抠图与画笔、AI 限制、导出与许可证                    | 打开/关闭                              |
| 页脚         | 刷新清空说明、对应部署源码和许可证入口                                | 外部 GitHub 链接                       |

移动端采用上下布局与固定底部导出栏；桌面采用左画布/图层、右工具。素材抠图页仅显示选中素材，辅助背景与虚线圈不进入导出。导出始终包含所有画布图层和文字效果，PNG 为动画第 0 帧。

首次单素材导入替换默认示例；后续追加，不清空其他素材。批量导入自动排布。同源副本共用蒙版和抠图历史，各图层独立保存构图参数；每素材最多 10 个历史状态。移除图层保留素材，删除素材移除其全部图层。刷新不保留素材或编辑状态。
