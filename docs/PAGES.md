# 前端页面与状态清单

单页编辑器，无路由库，无后端页面。

| 区域       | 内容与交互                                          | 关键状态                                   |
| ---------- | --------------------------------------------------- | ------------------------------------------ |
| 顶栏       | 品牌、设备本地处理提示、帮助                        | 帮助打开/关闭                              |
| 预览       | Canvas、播放暂停、拖动主体、尺寸/帧率/时长          | 动画播放、暂停、精修原图                   |
| 01 选素材  | 图片选择、AI、手动工具、画笔、撤销重做              | 导入中、无效文件、AI 下载/推理、失败、编辑 |
| 02 加点疯  | 四种动画卡片、速度、强度                            | 选中模板、连续预览                         |
| 03 调个味  | 大小、角度、位移、背景色/透明、文案/颜色/字号、时长 | 默认、自定义、透明背景                     |
| 导出操作栏 | GIF、PNG、编码进度与取消                            | 空闲、编码、取消、失败                     |
| 状态通知   | 读取、AI、导出和保存反馈                            | aria-live 非阻断提示                       |
| 导出结果   | 动图/封面预览、类型与大小、下载、分享、关闭         | 可长按保存、分享支持/不支持                |
| 帮助弹层   | 三步说明、手动工具语义、AI 下载和内存限制、许可证   | 打开、关闭                                 |
| 页脚       | 对应部署版本源码入口、许可证标识                    | 外部 GitHub 链接                           |

移动端采用上下布局与固定底部导出操作栏；桌面采用左预览、右工具。编辑工具切换不刷新页面，结果由用户关闭或再次导出替换。更换素材重置蒙版历史和构图，保留动画、文案与背景。精修画布显示原始素材和蒙版，不叠加动画构图，避免坐标混淆。
